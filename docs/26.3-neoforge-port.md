# Minecraft 26.3 NeoForge port

Branch `26.3neo` starts from `26.2-neo` (`ec3a2cae`). It targets Minecraft 26.3,
NeoForge 26.3.0.6-beta and Java 25. JEI uses the 26.3 API, version 31.0.0.11.
ModDevGradle 2.0.147 supplies the updated source transformation tools required
for the NeoForge development sources to compile.

The port updates rendering, swing animations, teleportation, movement and drop
APIs. Terrain obstruction checks retain the previous cobweb and bamboo sapling
exceptions. Catalyst fuel components retain burn times of 10 and 16 ticks.
Path actions survive node cloning and the new debug stream codec. The Wildfire
loot table loads only when Friends & Foes is installed.

## Verification

`JAVA_HOME=/usr/lib/jvm/java-25-openjdk ./gradlew build` succeeds: 151 tests,
no failures, errors or skipped tests. This includes shield animation, terrain
obstruction and path codec regression tests. The distributable contains
NeoForge metadata and no Fabric loader metadata or bundled optional mods.
No Minecraft client or server instance was launched.

## Optional integrations

Mutant Monsters and Friends & Foes have no published NeoForge 26.3 versions as
of 2026-09-21. Their guarded integrations remain in place, compiled against the
previous optional APIs without bundling those dependencies. Compatibility with
future releases needs verification when they become available. Do not install
their 26.2 jars in the 26.3 instance. The other compile-only integration uses
the available 26.3 release (G1hIVOrD 6.0.0).

## Manual verification

Use the Prism instance `NeoForge 26.3` with the installed Invasion jar.

1. Open a disposable test world. Check the creative tab, configuration screen,
   Nexus screen and JEI recipes for successful loading.
2. Start Nexus waves. Check spawning, building, mining, ladders, wave completion
   and HUD updates. Save and reload; the Nexus state should persist.
3. Check shield windup and cooldown, Enderman teleportation, traps, projectiles
   and entity rendering. Compare behavior with the 26.2 baseline.
4. Check that both catalysts retain their short furnace burn times. Without
   Friends & Foes, no missing Wildfire loot table should be reported.

These gameplay checks are pending user testing.
